# LeetCode 3612 - Process String with Special Operations I

題目係[呢度](https://leetcode.com/problems/process-string-with-special-operations-i/)

## 想法

### 古惑的 Code — 前後都行得㗎！

> 靈感來自《國產凌凌柒》袁詠儀把古惑的槍：「前後都射得㗎！」

寫一段 code，正行出嚟係 result，反行出嚟係佢嘅 reverse。一段 bytecode，兩個方向，兩個 output。

### 核心 idea：reversible interpreter

寫一個 reversible interpreter，forward execution 產生 result，backward execution 產生 reversed result。

- `%` (reverse) 只需要改 control flow direction (flip + jump)
- `#` (duplicate) 變成 bidirectional loop，counter=2
- `*` (delete) forward pop，backward 用 bubble 做 deferred deletion
- 程式碼 forward run = output，backward run = reversed output

咁 `%` 就完全係 control flow operation，唔需要真正 reverse data。

### Opcodes

| Opcode | 行為 |
|--------|------|
| `nop` | 乜都唔做 |
| `push ch` | append ch 到 output（如果有 unfilled bubble 喺 `len(output)` → fill bubble，唔 push） |
| `pop` | pop output top（如果有 filled bubble 喺 `len(output)` → unfill bubble，唔 pop） |
| `flip target` | 反轉 direction，jump 到 target |
| `jump target` | unconditional goto target |
| `jz target` | 如果 counter==0：pop counter stack，jump 到 target |
| `init_counter n` | push n 到 counter stack |
| `dec_counter` | decrement counter stack top |
| `push_bubble` | 記錄 `pos = len(output)` 到 bubble stack（unfilled） |
| `burst_bubble` | pop bubble stack top（discard entry） |

### Flip scaffold for %

```
start:      nop
            flip body_end       ← enter: flip direction, jump into body end
            flip end            ← reached when body exits backward
body_start: ...
            ...
body_end:   ...
            flip start          ← body exits backward here
            flip body_start     ← backward entry flips into body start
end:        nop
```

Forward execution：start → flip(body_end, dir=-1) → body backward → flip(end, dir=+1) → end。
Backward execution：end → flip(body_start, dir=+1) → body forward → flip(start, dir=-1) → start。

Body forward 出 "abc"，body backward 出 "cba" — reverse 就係 pure control flow。

### Bidirectional loop scaffold for #

```
start:            nop
                  init_counter 2
forward_compare:  jz end                    ← counter==0? pop & exit forward
                  jump body_start           ← enter body
                  jump backward_compare     ← (dead in forward, used by backward)
                  dec_counter               ← (dead in forward, used by backward)
body_start:       ...
body_end:         ...
                  dec_counter               ← (dead in backward, used by forward)
                  jump forward_compare      ← loop back forward
                  jump body_end             ← (dead in forward, used by backward)
backward_compare: jz start                  ← counter==0? pop & exit backward
                  init_counter 2
end:              nop
```

Forward path: init → jz(continue) → jump body_start → body → dec → jump forward_compare → ... → jz(exit) → end。
Backward path: end → init → jz(continue) → jump body_end → body backward → dec → jump backward_compare → ... → jz(exit) → start。

每個 direction 有自己嘅 init/dec/compare path，另一個 direction 嘅 instructions 會被 jump 跳過。

關鍵：`jz` fire 時 pop counter stack，確保 nested loops 嘅 counter 唔會互相干擾。

### Star scaffold for * (bubble)

`*` forward 就 pop，backward 要知刪乜 — 但 subexpression 未行完之前唔知。

解決：bubble = 將 stack 切開。`push_bubble` 開一個新 segment，第一個 push 入去嘅嘢係「犧牲品」。
Subexpression 正常行（push/pop 照做）。`burst_bubble` 丟走犧牲品，merge 返。

```
start:      nop
            jump body_start         ← forward path
            jump start              ← backward exit
            burst_bubble
body_start: ...
body_end:   ...
            pop                     ← forward path
            jump end
            jump body_end           ← backward entry
            push_bubble
end:        nop
```

Forward：body → pop。Backward：push_bubble → body backward → burst_bubble。

#### 靜態 `*` elimination

Compile 時追蹤 expected output length。如果 `*` 出現時 length=0，代表 pop 必定 no-op，唔 emit。
保證每個 emitted `*` 都有 real target。

## 解法

```python
from collections import deque


class Solution:
    def processStr(self, s: str) -> str:
        prog = self._compile(s)
        return self._execute(prog)

    def _compile(self, s):
        body = deque()
        length = 0
        for ch in s:
            if ch == '*':
                if length > 0:
                    self._wrap_star(body)
                    length -= 1
            elif ch == '%':
                self._wrap_flip(body)
            elif ch == '#':
                self._wrap_loop(body)
                length *= 2
            else:
                body.append(['push', ch])
                length += 1
        return self._assemble(body)

    def _wrap_star(self, body):
        start = ['nop']
        end = ['nop']
        body_start = body[0]
        body_end = body[-1]
        body.appendleft(['burst_bubble'])
        body.appendleft(['jump', start])
        body.appendleft(['jump', body_start])
        body.appendleft(start)
        body.append(['pop'])
        body.append(['jump', end])
        body.append(['jump', body_end])
        body.append(['push_bubble'])
        body.append(end)

    def _wrap_flip(self, body):
        if not body:
            return
        start = ['nop']
        end = ['nop']
        body_start = body[0]
        body_end = body[-1]
        body.appendleft(['flip', end])
        body.appendleft(['flip', body_end])
        body.appendleft(start)
        body.append(['flip', start])
        body.append(['flip', body_start])
        body.append(end)

    def _wrap_loop(self, body):
        if not body:
            return
        start = ['nop']
        end = ['nop']
        body_start = body[0]
        body_end = body[-1]
        fwd_cmp = ['jz', end]
        bwd_cmp = ['jz', start]
        body.appendleft(['dec_counter'])
        body.appendleft(['jump', bwd_cmp])
        body.appendleft(['jump', body_start])
        body.appendleft(fwd_cmp)
        body.appendleft(['init_counter', 2])
        body.appendleft(start)
        body.append(['dec_counter'])
        body.append(['jump', fwd_cmp])
        body.append(['jump', body_end])
        body.append(bwd_cmp)
        body.append(['init_counter', 2])
        body.append(end)

    def _assemble(self, body):
        instrs = list(body)
        # Phase 1: stamp each instruction with its index
        for i, instr in enumerate(instrs):
            instr.append(i)
        # Phase 2: resolve jump targets (target[-1] = resolved address)
        prog = []
        for instr in instrs:
            op = instr[0]
            if op in ('flip', 'jump', 'jz'):
                prog.append((op, instr[1][-1]))
            elif op == 'push':
                prog.append(('push', instr[1]))
            elif op == 'init_counter':
                prog.append(('init_counter', instr[1]))
            else:
                prog.append((op,))
        return prog

    def _execute(self, prog):
        pc, direction = 0, 1
        output = []
        counter_stack = []
        bubble_stack = []  # [[pos, filled], ...]
        while 0 <= pc < len(prog):
            op = prog[pc][0]
            if op == 'push':
                absorbed = False
                for i in range(len(bubble_stack) - 1, -1, -1):
                    if bubble_stack[i][0] == len(output) and not bubble_stack[i][1]:
                        bubble_stack[i][1] = True
                        absorbed = True
                        break
                if not absorbed:
                    output.append(prog[pc][1])
            elif op == 'pop':
                released = False
                for i in range(len(bubble_stack) - 1, -1, -1):
                    if bubble_stack[i][0] == len(output) and bubble_stack[i][1]:
                        bubble_stack[i][1] = False
                        released = True
                        break
                if not released and output:
                    output.pop()
            elif op == 'push_bubble':
                bubble_stack.append([len(output), False])
            elif op == 'burst_bubble':
                bubble_stack.pop()
            elif op == 'flip':
                direction = -direction
                pc = prog[pc][1]
                continue
            elif op == 'jump':
                pc = prog[pc][1]
                continue
            elif op == 'jz':
                if counter_stack and counter_stack[-1] <= 0:
                    counter_stack.pop()
                    pc = prog[pc][1]
                    continue
            elif op == 'init_counter':
                counter_stack.append(prog[pc][1])
            elif op == 'dec_counter':
                counter_stack[-1] -= 1
            pc += direction
        return ''.join(output)
```

## 備註

### Reversible computing 嘅 insight

- `%`：純 control flow（flip direction + jump），zero data manipulation。
- `#`：symmetric bidirectional loop，forward/backward 各有自己嘅 init/dec/compare path。
- `*`：唯一 non-reversible operation，用 bubble 解決 — stack segment 嘅第一個 push 係犧牲品。
- `jz` fire 時 pop counter stack — nested loops 唔會互相干擾。
- 靜態 `*` elimination：compile 時追蹤 expected length，`*` at length=0 唔 emit。

### Label relocation via object identity

每個 instruction 係一個 list，jump targets 直接 reference 目標 list object。
Wrap 時 in-place mutate deque（appendleft/append），唔 copy body。
Assemble 兩個 phase：stamp index → resolve `target[-1]`。O(n) total。

### Complexity

- Compilation：O(n)。
- Execution：O(output size × bubble depth)，bubble depth ≤ number of `*`。
- Output size 最大 O(2^k × m)，k = number of `#`，m = number of letters。
