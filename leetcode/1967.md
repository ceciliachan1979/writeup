# LeetCode 1967 - Number of Strings That Appear as Substrings in Word

題目係[呢度](https://leetcode.com/problems/number-of-strings-that-appear-as-substrings-in-word/)

## 想法

Naïve 做法係每個 pattern 獨立 check `pattern in word`，對於呢題 Easy 嘅 constraints 當然冇問題，但 adversarial input 可以 degrade 到 O(n × m)。

用 Aho-Corasick 可以**掃一次 text 就搵晒所有 pattern**。

**點解呢個方法好：**
- 掃 `word` **得一次**，每個 pattern 出現與否都知道 — 唔使擔心 potentially quadratic 嘅 overlap 數量。標準 Aho-Corasick 會 report 所有 occurrences，但 occurrences 數量可以係 O(T × P)：例如 `word = "aaa...a"`（長度 T）加 patterns `"a"`, `"aa"`, `"aaa"`, ...，每個 position 都會 match 所有長度 ≤ 當前位置嘅 patterns，total matches 係 quadratic。我哋呢度只需要知「有冇出現過」，所以要避免呢個 quadratic behavior。

## 解法

用 Aho-Corasick automaton：

1. 用所有 patterns **build 一棵 trie**。
2. **起 failure links**（BFS）— fall back 去最長嘅 proper suffix 同時又係 trie prefix（即係 KMP generalize 到 multiple patterns）。
3. **加 output links** — shortcut 去最近嘅 ancestor（經 fail links）而佢本身係 pattern 嘅結尾。
4. **Stream `word`** 過個 automaton。每個 character follow transitions；去到 pattern-end node（或者經 output links 到達），count 佢然後 zero out 避免 double-count duplicates。

## Code

```python
from collections import deque

class Solution:
    def numOfStrings(self, patterns: list[str], word: str) -> int:
        # --- Aho-Corasick automaton ---
        nxt = [[0] * 26]   # nxt[node][char] -> child node
        fail = [0]
        out = [0]
        cnt = [0]

        def new_node():
            nxt.append([-1] * 26)
            fail.append(0)
            out.append(0)
            cnt.append(0)
            return len(nxt) - 1

        # Insert all patterns into the trie
        for p in patterns:
            u = 0
            for ch in p:
                c = ord(ch) - ord('a')
                if nxt[u][c] == -1:
                    nxt[u][c] = new_node()
                u = nxt[u][c]
            cnt[u] += 1

        # Build failure and output links via BFS
        q = deque()
        for c in range(26):
            v = nxt[0][c]
            if v != -1:
                fail[v] = 0
                q.append(v)
            else:
                nxt[0][c] = 0

        while q:
            u = q.popleft()
            out[u] = fail[u] if cnt[fail[u]] else out[fail[u]]
            for c in range(26):
                v = nxt[u][c]
                if v != -1:
                    fail[v] = nxt[fail[u]][c]
                    q.append(v)
                else:
                    nxt[u][c] = nxt[fail[u]][c]

        # Stream word through the automaton
        ans = 0
        u = 0
        for ch in word:
            u = nxt[u][ord(ch) - ord('a')]
            v = u if cnt[u] else out[u]
            while v != 0:
                ans += cnt[v]
                cnt[v] = 0
                nxt_out = out[v]
                out[v] = 0
                v = nxt_out
            if cnt[u]:
                ans += cnt[u]
                cnt[u] = 0

        return ans
```

## 速度

| | Cost |
|--|--|
| **Time** | O(T + P)，T = len(word)，P = Σlen(pattern)。Output link traversal amortized O(P)，因為每個 node 最多 fire 一次。 |
| **Space** | O(P × 26) for trie transitions。 |

## Lower Bound

呢個 O(T + P) 其實 **hit 到 theoretical lower bound**：考慮得一個 pattern 同 text 係同一個 string 嘅 case — 你冇辦法唔讀晒所有 input 就 determine 到答案，所以任何正確嘅 algorithm 都要至少 O(text + pattern) time，而我哋正正做到呢個。

## 備註

對於呢題 Easy — Aho-Corasick 當然係 overkill。但當 text 好長、patterns 好多、需要**保證 linear time** 嘅時候（例如 multi-pattern grep、network intrusion detection、DNA motif scanning），呢個就係 go-to 嘅方法。
