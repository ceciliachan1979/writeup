# LeetCode 3518. Smallest Palindromic Rearrangement II

題目係[呢度](https://leetcode.com/problems/smallest-palindromic-rearrangement-ii/)

## 想法

首先觀察：任何 palindrome 都係由中間向外對稱，所以我哋只需要決定左半邊，右半邊自動決定。如果 string length 係奇數，中間嗰個 character 係奇數次數嘅 character（最多得一個）。

所以問題變成：將所有 character 嘅出現次數除以 2（向下取整），用呢啲 "half counts" 排列左半邊，搵第 $k$ 小嘅排列。

## 搵第 $k$ 小嘅排列

我哋逐個位置由左到右決定。對於每個位置，按字典序逐個試 character $c$，問：如果呢個位置固定放 $c$，餘下位置有幾多個合法排列？如果呢個 count $\geq k$，答案嘅下一個 character 就係 $c$；否則將 $k$ 減去 count，繼續試下一個 character。

所以核心問題係：$n$ 個位置，有 block sizes $a_1, a_2, \ldots, a_m$（每種 character 嘅剩餘數量），有幾多個排列？答案係 multinomial coefficient：

$$\binom{n}{a_1, a_2, \ldots, a_m} = \frac{n!}{a_1! \cdot a_2! \cdots a_m!}$$

呢條 formula 可以用「暫時幫相同嘅 character 加 label」理解。首先將所有 character 當成唔同：例如 $a_1$ 個 `a` 變成 $a_1,a_2,\ldots,a_{a_1}$，咁就有 $n!$ 個排列。但移除 `a` 嘅 labels 之後，每個真正嘅排列都被重複計咗 $a_1!$ 次，所以要除以 $a_1!$。逐種 character 移除 labels，就再除以 $a_2!,a_3!,\ldots$，最後得到上面嘅 multinomial。

## 早停嘅技巧

但係 $k$ 最大係 $10^6$，而 multinomial 可以大到天文數字，所以我哋唔想計 exact value — 只需要知道係咪 $\geq k$。

**逐種 character 揀位置：** 先喺 $n$ 個位置揀 $a_1$ 個放第一種 character，再喺餘下 $n-a_1$ 個位置揀 $a_2$ 個放第二種，如此類推：

$$\binom{n}{a_1, a_2, \ldots, a_m} = \binom{n}{a_1} \cdot \binom{n - a_1}{a_2} \cdot \binom{n - a_1 - a_2}{a_3} \cdots$$

呢個亦可以直接由 factorial algebra 驗證：相鄰兩項嘅 factorial 會 cancel，最後只剩低 multinomial 嘅分子同分母。

**將 binomial 寫成 fractions 嘅乘積：** 利用 $\binom{n}{r}=\binom{n}{n-r}$，先令 $r=\min(r,n-r)$，於是 $r\leq n/2$。然後 cancel factorial：

$$
\binom{n}{r}
= \frac{n!}{r!(n-r)!}
= \frac{n-r+1}{1}\cdot\frac{n-r+2}{2}\cdots\frac{n}{r}
$$

由左至右計，乘完頭 $i$ 個 fractions，即係

$$\frac{n-r+1}{1}\cdot\frac{n-r+2}{2}\cdots\frac{n-r+i}{i},$$

個結果正正係 $\binom{n-r+i}{i}$。所以雖然單獨一個 fraction 未必係整數，每次將下一個分子乘入、再除以下一個分母之後，結果一定係整數。

另外，因為 $r\leq n/2$ 同埋 $i\leq r$：

$$
n\geq 2r\geq r+i
\quad\Longrightarrow\quad
n-r+i\geq 2i
\quad\Longrightarrow\quad
\frac{n-r+i}{i}\geq 2.
$$

所以每處理一個 fraction，running product 都至少 double；如果 $r=0$，就完全唔需要處理 fraction。

因此 running product 一旦 $\geq k$ 就可以安全早停，而且最多處理 $\lceil\log_2 k\rceil$ 個 fractions。外層最多掃 26 種 character，所以一次 count 係 $O(26+\log k)=O(\log k)$。

## 解法

```python
from collections import Counter

class Solution:
    def smallestPalindrome(self, s: str, k: int) -> str:

        def count_arrangements(remaining, cap):
            result = 1
            left = sum(remaining.values())
            for c in remaining.values():
                if c == 0:
                    continue
                r = min(c, left - c)
                for i in range(1, r + 1):
                    result = result * (left - r + i) // i
                    if result >= cap:
                        return cap
                left -= c
            return result

        freq = Counter(s)

        # Half counts for left half
        remaining = {}
        middle = ''
        for ch, cnt in sorted(freq.items()):
            remaining[ch] = cnt // 2
            if cnt % 2 == 1:
                middle = ch

        chars = sorted(remaining.keys())
        half_len = sum(remaining.values())

        if count_arrangements(remaining, k) < k:
            return ''

        result = []

        for _ in range(half_len):
            for ch in chars:
                if remaining[ch] == 0:
                    continue
                remaining[ch] -= 1
                cnt = count_arrangements(remaining, k)
                if cnt >= k:
                    result.append(ch)
                    break
                k -= cnt
                remaining[ch] += 1

        left = ''.join(result)
        right = left[::-1]
        return left + middle + right
```

## 速度

設 alphabet size 為 $\sigma\leq 26$。每個位置最多試 $\sigma$ 個 characters；每次 `count_arrangements` 掃 $\sigma$ 個 counts，而真正執行嘅 fraction steps 最多 $O(\log k)$ 次。半邊有 $O(n)$ 個位置，所以時間係 $O(n\sigma(\sigma+\log k))=O(n\log k)$，space 係 $O(\sigma+n)=O(n)$（包括答案）。

對於呢題 $k \leq 10^6$，所以 $\log_2 k < 20$，practical 上接近 $O(n)$。
